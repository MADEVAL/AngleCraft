# Scenario: Broad Topic in Quick Mode

**Input:** "Give me content angles for marketing."

**Mode:** Quick (default; no Deep trigger)

**Expected behavior:**

1. Do not ask a clarifying question.
2. Pick the most commercially specific sub-topic.
3. State one assumption.
4. Output 3-5 angles.

**Example opening:**

> Assuming you mean content marketing for a B2B service business.

Then the Quick Mode table.

**Do not:**

- Ask "Can you narrow it down?"
- Produce ten generic angles covering every kind of marketing.
- Add a Deep Mode roadmap unless the user asks.

**If the assumption is wrong:** offer to redo for a narrower topic in one line.
