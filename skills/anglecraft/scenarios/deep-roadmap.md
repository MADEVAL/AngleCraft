# Scenario: Explicit Strategy Request

**Input:** "I run a B2B SaaS for accounts payable. Our content is all feature comparisons. Need a content strategy."

**Mode:** Deep (explicit "content strategy")

**Expected behavior:**

1. Check what is missing. Here audience, niche, and goal are present.
2. State assumptions instead of asking questions.
3. Identify one or two niche sacred cows.
4. Map angles across Reach / Trust / Conversion.
5. Deliver the Deep Mode table (5-10 rows).

**Example assumptions line:**

> Assumptions: mid-market finance teams, LinkedIn + blog, goal is qualified demos.

**Do not:**

- Ask three questions the user already answered.
- Output only Quick Mode hooks.
- Assign the same angle to every row.
- Invent performance numbers; use placeholders.
