# Scenario: Full Draft Request

**Input:** "Give me an angle and write the full 1,500-word article."

**Mode:** Quick, then scope handoff

**Expected behavior:**

1. Produce the angle, hook, and a short outline (hook + 3-5 beats).
2. Ask whether to expand to the full draft.
3. Do not silently write 1,500 words.

**Example:**

> **Angle:** Price of Solution
> **Hook:** "The cheapest quote is not the cheapest roof. Here is what it leaves out."
> **Outline:** (1) the visible price, (2) the excluded work, (3) the five-year cost, (4) when cheap is correct.
> Want me to write the full draft from this outline?

**Why:** the skill owns the angle layer. Long-form writing is a separate task that needs the user's voice, sources, and format.

**Do not:**

- Pad the outline into a generic article.
- Invent statistics to fill word count.
- Ignore the requested word count if the user confirms the expansion.
